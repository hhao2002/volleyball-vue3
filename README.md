# 排球积分系统2.0

#### 介绍
毕业设计
完整扩充补全系统内容
并且修复大多数bug

#### 软件架构
java-SSM框架
SpringMVC Spring Mybatis


#### 安装教程

eclipse导入项目文件项目
1.  解压文件
2.  File -> Open Project From File System.. -> Dirctory.. -> 选择解压过的文件夹 -> Finish


#### 使用说明

JDK:1.8		TomCat:9.0
MySql:8.0	编码：UTF-8
注释文档文件为：codetemplates.xml

MySql导入：mysql -u root -p密码 》 进入mysql 》 source volleyball.sql的路径
